## 🚨 Sofort anhalten, wenn …

| Symptom | Bedeutung |
|---|---|
| Knacken aus dem Lenkkopf beim Bremsen | Steuersatz hat Spiel → Mutter lösen sich |
| Lenker verdreht sich beim Bremsen | Vorbau rutscht im Schaft → **Bruchgefahr** |
| Lenkung rastet in Mittelstellung ein | Steuersatz-Lager eingelaufen (Pitting) |
| Bremshebel geht bis zum Lenker durch | Zug gerissen / Belag verschlissen / Zug ausgehängt |
| Bremse blockiert von selbst | Rückstellproblem → Felge wird heiß, Reifen kann platzen |
| Schleifgeräusch, das mit der Geschwindigkeit zunimmt | Lager, Bremse, Schutzblech, Speiche |
| Klackern bei jeder Kurbelumdrehung | Kette zu lang/kurz, Schaltröllchen, Pedal, Innenlager |
| Licht flackert | lose Lötstelle, Kabelbruch |
| Rad „eiert“ sichtbar | Speichenbruch, Felgenschaden |
| **Knall + Bremshebel ohne Funktion** | 🔴 **Felgenbruch** – bei abgefahrener Bremsflanke möglich |
